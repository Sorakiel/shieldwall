# Шрифт интерфейса

`NotoSans-Regular.ttf` — Noto Sans с поддержкой кириллицы.
Источник: [Noto Fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans).
Лицензия SIL Open Font License 1.1 находится в `OFL-NotoSans.txt`.

Шрифт входит в исходники и копируется CMake рядом с программой.
Скачивание шрифта при запуске не требуется.
